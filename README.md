## 🌟 Flagship Projects

- **[Deal Aggregator](https://github.com/Sulakshana29/Deal_Aggregator)**  
  Cloud-native 3-tier architecture with Docker and Kubernetes (KinD). Features automated CI/CD via GitHub Actions, Trivy vulnerability scanning, and real-time observability using Prometheus and Grafana.  
  *Stack: Node.js, Express, MongoDB, Docker, KinD, Prometheus, Grafana, AWS EC2*

- **[CyberX – Web Vulnerability Scanner](https://github.com/Sulakshana29/CyberX)**  
  Automated multi-threaded security testing engine targeting OWASP Top 10 web vulnerabilities (SQLi, XSS, sensitive headers) with structured vulnerability reporting.  
  *Stack: Python, Flask, Vercel, REST APIs*  
  👉 **[Live Web App](https://cyberx-6jjg.onrender.com)** 

- **[Ninnadaya Media Competition Portal](https://github.com/Sulakshana29/ninnadaya)**  
  Production-grade web portal delivered for an inter-school media competition. Handles end-to-end contestant registration, asset submissions, and role-based access control (RBAC).  
  *Stack: Next.js, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Storage), Vercel*  
  👉 **[Live Portal](https://ninnadaya.vercel.app)**

- **[Cloud Policy Guard](https://github.com/Sulakshana29/cloud-policy-guard)**  
  Security CLI tool written in Python that parses Terraform execution plans to detect and block over-permissive IAM policies before deployment.  
  *Stack: Python, Terraform JSON Parsing, AWS IAM Policy Engine*

- **[Cloud SOC & Honeypot Detection Lab](https://github.com/Sulakshana29/cloud-siem-honeypot)**  
  Cloud security monitoring lab deploying a Cowrie SSH honeypot via Terraform on AWS. Aggregates telemetry to Wazuh SIEM to analyze real-world brute-force and credential harvesting attacks.  
  *Stack: AWS, Terraform, Cowrie Honeypot, Wazuh SIEM, Linux*
